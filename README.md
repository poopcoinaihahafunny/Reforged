#reforged
Node Reforged

A performance-focused Node.js fork designed to improve memory efficiency, throughput, and latency while maintaining compatibility with existing Node.js applications.
Goals

    Measure performance against upstream Node.js

    Improve memory usage and CPU efficiency

    Preserve Node.js API compatibility

    Build reliable benchmarks and regression tests

Project principles

    Benchmark before optimizing

    Keep changes small and testable

    Preserve upstream license notices

    Never claim performance improvements without reproducible results

Status

Early development.
